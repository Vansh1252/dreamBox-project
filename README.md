## About

DreamBox offers event photography, event videography, video production, live streaming and corporate video services across Dubai, the UAE and the GCC. This site presents those services, shows the company's work and makes it easy to get in touch by email or WhatsApp.

## Features

- **Responsive layout** that works on desktop, tablet and mobile
- **Navigation** for Home, Event Photography, Event Videography, Video Production, Live Streaming, Corporate and Contact
- **Service sections** describing each offering
- **Contact details** with email and WhatsApp links
- **No build step:** plain HTML and CSS, deployed on Vercel

## Project structure

~~~text
├── index.html   # Page markup and content
└── style.css    # Styles and responsive breakpoints
~~~

## Run locally

~~~bash
git clone https://github.com/Vansh1252/dreamBox-project.git
cd dreamBox-project
~~~

Open `index.html` in your browser, or serve the folder with any static server, for example `npx serve .`
